# Diplay for Lynk&Co 09 PHEV

**面向领克 09 PHEV 使用场景优化的 CarPlay 分支。**

简体中文自述现统一维护在仓库首页，请阅读 [完整项目说明、相对上游的改进及适配范围](README.md)。
